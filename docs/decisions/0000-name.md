# ADR 0000: Project name "Kekal"

- Status: accepted
- Date: 2026-11-13

## Context

The project needs a short name that works in English and Malay. "Kekal" is Malay for "lasting" or "permanent", which matches
the promise: the warranty stays good even if the shop does not. Before committing to it we checked for an active Solana project
with the same name, to avoid confusing judges and users.

## Check (2026-11-13)

- `gh search repos kekal` (30 results) and `gh search repos "kekal solana"` (0 results): no Solana or warranty project named
  Kekal. Matches are personal repos and an unmaintained JavaScript library (`aikoven/kekal`).
- `npm search kekal`: the unscoped `kekal` package exists (same unmaintained library, last published 2022). It is unrelated.

## Decision

Keep the name **Kekal**. Workspace packages are private and scoped (for example `@kekal/sdk`) and are not published to npm, so
the existing unscoped package does not collide.

## Fallback

If a conflicting active Solana project named Kekal appears, rename to "Jamin" everywhere and record a new ADR.
